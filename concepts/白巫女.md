# 白巫女

## 定义与机制

- 白巫女通过替秽鬼承受污秽、净化其灵魂，给它们带来解脱（[[法腾]]的记录 1）。
- 与生俱来的抗性保护灵魂、确保不会失去理性；但污秽会遗留在肉体里带来痛苦——历代白巫女“由于净化的负荷无人享有长寿”。
- 白巫女持有[[遗物宝具|护身宝具]]缓解痛苦；传说白巫女天生额头上刻有闪闪发光的徽章（[[遗物宝具|宁菲莉雅的戒指]]）。

## 传承制度与血脉

- 称号与出生地相关，由前一代白巫女命名；继承人自血脉或候选中产生。
- 系谱（补完 + 文本集互证）：**[[儿汝莉德]]（古老民族巫女）→ 女[[宁菲莉雅]]（第一代·黎明）→ 女[[伊莉斯]]（第二代·风）→ 女[[芙莉蒂雅]]（第三代·泉）→（人造/分身）[[莉莉]]**——白巫女是[[古老民族]]巫女血脉的延续，承载[[不死契约与不死者|契约印]]（见[[剧情疑点与未解之谜]]疑点 5）。
- 守护者体系（[[白教]]选拔、地下修炼场修行）与之配套。

## 人造白巫女（幼年白巫女们）

第三代白巫女芙莉蒂雅无子嗣，[[法腾]]以其血肉为基制出**最终九个**人造白巫女。她们与芙莉蒂雅度过一段美好时光，被其视如己出；污秽转移仪式被拒后四散各地：

| 称呼（补完） | 去向 | 结局 |
|---|---|---|
| 白教区的[[白教区的莉莉]] | 被格罗亚带至白教区，由西丽德守护 | 沉睡于教区顶层；主角继承其名 |
| 王城的[[都城的巫女]] | 被国王选中带往王城（血脉计划） | 死于国王寝室 |
| 堡垒的[[双生堡垒的白巫女]] | 被尤利乌斯安置于双生堡垒 | 未能逃脱死亡命运 |
| 悬崖村/魔术协会/地下墓穴/地牢出口/禁区的白巫女 | 逃散或避难 | 陆续殒命 |
| 禁忌领域的白巫女 | 留在禁区 | 被用作实验 |
| 第九位（主角[[莉莉]]） | 白教区教堂苏醒 | 成为故事主角 |
