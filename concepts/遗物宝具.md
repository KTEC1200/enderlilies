# 遗物与宝具

> 文本集“遗物”章节的物品目录。条目格式：名称 — 说明 — 主人/象征（归属不明或推测处已标注）。

## 白巫女与守护者相关

- **脏污的银念珠** — 守护者所携念珠（地下教堂修炼、选拔传统）→ [[西丽德]]、[[格罗亚]]等守护者
- **白巫女的耳环** — 芙莉蒂雅 14 岁继位时由先代所赠 → [[芙莉蒂雅]]（传承）
- **光耀的守护宝具** — 解读石板文书恢复力量、以法腾的魔法炼成的护身符，可减轻净化之痛 → [[莉莉]]（护身符）
- **曾经失去的东西**（白花发饰） — 芙莉蒂雅污秽染身后仍制作赠予幼小白巫女们 → [[芙莉蒂雅]]（母爱/牵挂）
- **芙莉蒂雅的戒指** — 第三代白巫女之证 → [[芙莉蒂雅]]
- **白巫女的雕像** — 信徒所制黎明之白巫女像 → [[宁菲莉雅]]（信仰）；残存/倒塌两像的象征解读见[[剧情疑点与未解之谜]]疑点 10（黎明=信仰基石；风之白巫女像倒塌=命运崩塌与防线失守＋白教权威衰落）
- **白巫女娃娃** — 偏远少女为想念泉之白巫女而制 → [[芙莉蒂雅]]（民众之爱）
- **纯净清泉的圣水** — 芙莉蒂雅出生地边境之水；白巫女名字与出生地有关、由前代命名
- **魔线脚链** — 伊莱恩为行走困难的芙莉蒂雅编制 → [[伊莱恩]] → [[芙莉蒂雅]]（友情）
- **污秽的幻影** — 饱受污秽侵蚀的白巫女幻影，反映过去或未来无人知晓 → 疑指[[芙莉蒂雅]]

## 古老民族相关（含戒指群）

- **风化的战士项链** — 古老民族之物，“据说他们曾通过古代咒术，统治了世界”
- **儿汝莉德的戒指** — 战士赠巫女之戒（[[费林]] × [[儿汝莉德]]，跨生死的爱恋）
- **玛尼萨的戒指** — 古老民族爱花女子之戒，在白巫女手中会发光（魔术协会保管）
- **加莉比雅的戒指** — 记载地下巫女的存在
- **雅若拉的戒指** — “巫女与污秽同在，射杀的巫女雅若拉”（费林解读）
- **柯蒂斯的戒指** — “巫女继承了灵魂，引导的巫女柯蒂斯”（费林解读；建国前古物）
- **莉柯莉斯的戒指** — “巫女与灵魂在战场上起舞，切割的巫女莉柯莉斯”（费林解读；打败魔族时的战利品）
- **宁菲莉雅的戒指** — 黎明之白巫女之名（额头徽章传说）

## 魔女与魔术师相关

- **破裂的魔石** — [[伊莱恩]]充入结界魔力之物（破碎后仍保有一点魔力）
- **污秽侵蚀的魔女之书** — 伊莱恩的结界魔法书（被肉瘤腐蚀仍存力量）
- **生锈的蓝色花卉装饰** — [[伊莱恩]]收到的第一份礼物；成为秽鬼时装饰脱手、被雨水冲走
- **异端者的面具** — [[法腾]]系禁区魔术师防瘴毒工具
- **秽鬼之指** — 法腾以污秽制造的人造魔术工具
- **血染的丝带** — 少女的丝带被血染成深红，成秽鬼后仍珍惜保留（彻底未名者，无任何交叉线索）
- **带有污秽的刀** — 都城普通厨师之刀，主人被狂气吞噬后杀了许多人（非剧情核心人物）

## 王室相关

- **腐朽的王冠** — 国王象征，被弃于远离都城处 → [[国王]]（王权腐朽的隐喻）
- **破损的音乐盒** — 边陲古老摇篮曲；赠言“我心爱的孩子，让我们在梦中相见”（无法确认具体角色——“战斗中破裂”暗示战士主人，为战死士兵的群像缩影）
- **七彩羽毛头饰** — [[西丽亚]]赠妹妹[[西丽德]]的魔术头饰（她从未佩戴）
- **伊莉斯的戒指** — 风之白巫女之证（魔术师们为护白巫女打造的魔术工具系列）
