# 莉莉（主角）

## 简介

在[[舞台与地点|白教区]]苏醒的少女，故事的主角。醒来时无法言语、记忆空白，被黑色骑士[[费林]]引导踏上旅途。

**身份**：她是[[法腾]]制出的人造白巫女中**最新诞生的第九位、最小的“妹妹”**（八名幼年白巫女与新近诞生的第九位或逃离或带走，离开母亲芙莉蒂雅身旁；其中一位被[[格罗亚]]选中带往白教区，即[[白教区的莉莉]]；主角或与其一同被安置到白教区后沉睡，见[[剧情疑点与未解之谜]]疑点 1）。苏醒前她经历了污秽转移仪式——仪式因芙莉蒂雅的拒绝而未成，她身上仍带着被转移/继承的污秽。名字“莉莉”并非她本名：她在[[舞台与地点|白教区]]净化[[西丽德]]后从记忆中“取回”这个名字，而该名字的真正主人是西丽德守护的[[白教区的莉莉]]——结局 C 中她在教区顶层见到沉睡的莉莉，读其笔记后**继承了“莉莉”的名字与遗愿**（剧情补完；文本集费林台词：幸存者能够继承逝者的记忆和遗愿）。

她与[[芙莉蒂雅]]的关系贯穿始终：结局 B 中她选择与化为污秽之王的芙莉蒂雅一同坠入深渊（“你……就是我啊”）；结局 C 中她以古代石板与修复的[[遗物宝具|光耀的守护宝具]]净化了“最初与最终的污秽”，解放母亲与所有逝者。
