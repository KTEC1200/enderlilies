# 莉莉的旅途与三个结局

## 旅途

[[莉莉]]（主角）在[[舞台与地点|白教区]]苏醒后，与黑色骑士[[费林]]同行。两条岔路殊途同归：

- **向上（悬崖村线）**：英雄[[格落特]]守护着不存在的事物、[[西方商人]]化作徘徊的乌鸦、[[悬崖村村长]]厌恶自己的模样、[[无头骑士]]沦为无头怪物；哀悼死在屋中的幼年白巫女后，被城堡高墙阻断。
- **向下（魔女森林线）**：淹没的[[魔术协会与国家魔术师团|魔术协会]]中，花与菌的恋人[[花之魔女|生]][[菌之魔术师|死]]相隔，倒流瀑布旁是另一位白巫女的遗体，最下方是牵挂挚友的[[伊莱恩]]。
- 两线汇于**地下墓穴**：黑色骑士在此坦白古老民族身份；净化[[西丽亚]]后纯白的身影（芙莉蒂雅的幻影）指引他们前往边陲之泉。
- **双生堡垒**：与异变士兵、[[腐龙的孤儿|腐龙]]交锋，顶端忏悔室[[狼]]亮出利爪（给予少女翻越阻碍之力的礼物）。
- **地牢**：窥见[[海尼尔]]为白巫女出逃拼尽全力的记忆；那位白巫女死在出口前。
- 途中**逆时序支线**（结局 C 需要）：重返王城（国王寝室中死去的[[都城的巫女]]、王座下安眠的[[尤利乌斯]]）、深入[[舞台与地点|禁区]]（[[迷瑞尔]]巨怪化仍守护恋人、法腾死前仍在研究），并在禁区实验室知晓“莉莉作为人造白巫女出生”的事实；收集法腾藏匿的古代石板，回到白教区。

## 结局 A：净化（Truth remains in the Abyss. Tragedy, never ceasing.）

向前抵达边陲之泉。芙莉蒂雅承担了莉莉的污秽（文本集：她希望莉莉“自由地……活着”），莉莉净化她后离开。真相埋在深渊里，悲剧尚未结束。

## 结局 B：深渊（Being as one, we shall never be apart.）

不顾残缺信息、执意解救芙莉蒂雅的路线。少女直面**化为秽鬼之王的芙莉蒂雅**（根源的污秽令净化显得无力），最终选择陪她坠入深渊、融为一体：“你……就是我啊……我……终于……能够安眠了……”（因为她们本就是一人）。

## 结局 C：尾声（感谢你一直陪伴着我）

收集全部残缺信息后重走大地：在白教区顶层净化[[格罗亚]]，见到**做着不会醒来的梦的[[白教区的莉莉]]**，读其笔记、继承“莉莉”之名；于教堂地下以古代石板与法腾的研究修复[[遗物宝具|光耀的守护宝具]]。最终在“黎明的祷告”中净化最初与最终的污秽，解放母亲芙莉蒂雅与所有逝者；费林解开最后的心结（黑骑士守望莉莉完成一切）。莉莉为众人建成坟墓：“有我们，不再寂寞了吧？……你也有我。”
