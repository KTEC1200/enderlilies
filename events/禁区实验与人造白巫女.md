# 禁区实验与人造白巫女（净化仪式）

## 概要

[[双生堡垒防御战]]后的和平期，由[[法腾]]领导、经当代[[国王]]与[[格罗亚|守护者之长]]准许的禁忌研究。表面为治疗白巫女，实际是“杂糅着各方私欲的肮脏产物”。

## 关键环节

1. **灵药（不死灵药）**：源自白巫女污秽肉瘤的研究，令服者化为秽鬼后保存自我意识——不死骑士团与异变守卫的来源。
2. **人造白巫女**：法腾以创造生命/改变生命的魔术（文本集禁书残篇）制出**最终九个**幼年人造白巫女（补完 Part1 称“因为第三代白巫女没有子嗣，在法腾研究下制作出了九位人造白巫女”）。她们与芙莉蒂雅度过一段美好时光。
3. **污秽转移仪式（净化仪式）**：在芙莉蒂雅失去意识期间，人们将她身上的污秽转移到身边幼年白巫女们身上。她醒来拒绝：“我想交给她们的是希望……而不是污秽。”——仪式未能按计划完成。仪式本质是**分摊机制**，拒绝=超载失控的导火索；“黑暗解读”（实验体数量存疑）保留为无实证支线；主角吸收污秽存活并在结局 C 完成净化，客观上验证克隆体可作污秽容器的理论（见[[剧情疑点与未解之谜]]疑点 8）。
4. **白巫女们的离散**：仪式后，八名幼年白巫女与新近诞生的第九位（即主角[[莉莉]]）或逃离或被带走，离开芙莉蒂雅身旁，散落于白教区（[[白教区的莉莉]]，被格罗亚带走）、双生堡垒（[[双生堡垒的白巫女]]，被尤利乌斯安置）、王城（[[都城的巫女]]，被国王选中）、悬崖村、魔术协会、地下墓穴、地牢出口等处。
5. **守护宝具的修复**：法腾秘密解读古代石板（瞒着国王，交予信赖之人），与伊莱恩联手准备，最终以魔法炼成[[遗物宝具|光耀的守护宝具]]。
6. **失控**：芙莉蒂雅拒绝仪式后成为污秽的源头，污秽自地底蔓延、死亡之雨降临；实验体与罪犯秽鬼化；国王逐渐成为法腾的敌人。
