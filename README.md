# ENDER LILIES 文本集 · 知识图谱

> 本仓库由 AI 辅助整理（Hermes + LLM Wiki + Obsidian），旨在将《ENDER LILIES》的碎片化叙事重构为可交互、可探索的知识网络。

---

## 📖 项目简介

《ENDER LILIES》以碎片化的文本（人物记忆、遗物描述、场景笔记）讲述了一个关于污秽、白巫女与不死骑士的悲壮故事。本仓库不仅收录了完整的游戏文本整理，更通过自动化工作流，将零散的台词转化为具有双向链接的**人物图谱**和**事件时间线**，帮助你理清复杂的人物关系与隐藏剧情。

---

## 📂 文件结构说明

| 文件 / 文件夹 | 内容说明 |
| :--- | :--- |
| **`ENDER LILIES 文本集.md`** | 原始文本总集，包含所有人物记忆、对话剧情、笔记内容和遗物描述（由 KTEC 个人整理）。 |
| **`sources/`** | 存放自整理的文本集。 |
| **`entities/`** | **人物卡片目录**。每个重要角色（如黑色骑士费林、西丽德、芙莉蒂雅等）都有一个独立页面，包含简介、关键台词、关联人物链接。 |
| **`events/`** | **事件目录**。梳理了双生堡垒防御战、死亡之雨降临等关键剧情事件的时间线。 |
| **`index.md`** | 仓库总索引，AI 自动生成的人物关系摘要和快速导航入口。 |

---

## 🗺️ 建议食用方式（阅读指南）

为了获得最佳的沉浸式探索体验，强烈建议使用 **Obsidian** 打开本仓库：

1.  **查看关系图谱**：在 Obsidian 中打开“关系图谱”（Graph View），可以看到人物之间复杂的“守护”、“憎恨”、“继承”关系。
2.  **双向链接跳转**：点击任意人物名（如 `[[泉之白巫女芙莉蒂雅]]`），即可跳转到对应的人物卡片，像玩解谜游戏一样顺着线索读下去。
3.  **AI 辅助完善**：如果你发现某些关系缺失或想补充个人见解，可以在对应页面直接编辑，提交 Pull Request 或本地保留即可。

---

## 🤖 自动化工作流说明

本仓库的知识图谱由以下工具联动生成：
- **Hermes Desktop**：执行自动化指令。
- **LLM Wiki Skill**：从原始文本中提取实体、关系并生成 Markdown 页面。
- **Obsidian**：作为知识展示与人工审阅的前端。
